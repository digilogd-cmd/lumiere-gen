# 브라우저 플레이북 — 생성형 뤼미에르의 "생성 작업 해 줘"

생성형 프로젝트가 **브라우저 작업 대기**에서 멈추면, Claude(크롬 확장 `mcp__claude-in-chrome__*`)가 이 순서대로 Google Flow·AI Studio·Flow Music을 움직여 결과를 받아 온다.
2026-10-08 첫 실제 시험(`work/생성_뤼미에르_A`)에서 **직접 해 보고 확인한 것**만 적었다. 화면은 자주 바뀌니 버튼 이름(aria-label)으로 찾는 방법을 우선한다.
게이트 영상제작 지침서(§4 TTS·§6 Flow·§12 브라우저)의 원칙은 그대로 유효하다.

---

## 0. 순서 한눈에

```
python -m editteam gen-jobs --name <프로젝트>          ← 남은 일 보기(프롬프트·레퍼런스·받을 곳)
  1) 캐릭터 시트 그림(sheet_*) → 받기 → --done
  2) 샷 그림(img_*) — 시트를 레퍼런스로 붙여서 → 받기 → 눈으로 확인 → --done
  3) 영상(vid_*) — 샷 그림을 시작 프레임으로 → 받기 → --done   (크레딧! 한도 안에서만)
  4) 목소리(voice_*) — AI Studio → 받기 → --done
  5) 음악(music_main) — Flow Music → 받기 → --done
python -m editteam bg run --name <프로젝트>             ← 이어 가기(자막·조립·종편·썸네일·완성 폴더)
```

- 등록: `python -m editteam gen-jobs --name <프로젝트> --done <id> --file "<크롬 다운로드 폴더>\받은파일"` (`--file latest` = 크롬 다운로드 폴더의 가장 최근 파일).
  이미지·영상은 **이때 워터마크(✦)가 자동으로 지워진다**(`gen/tools/wm_remove*.py`). 원본은 단계 폴더의 `받은/`에 남는다.
- 실패: `--fail <id> --note "이유"`. 재시도 한도(설정 `생성.재시도_한도`, 기본 2)를 넘으면 '포기' → 단계가 대체 방법을 쓴다
  (그림: 같은 장면 다른 그림 / 영상: 그림 + 켄 번즈 / 목소리: 윈도우 Heami 임시 음성 / 음악: 키트 배경음).
- 크롬 다운로드 폴더: 크롬 설정(Preferences)에서 자동으로 찾는다(예: 크롬 기본 '다운로드' 폴더). `gen-jobs --downloads` 로 최근 파일 확인.
- **받은 파일은 작업 폴더에서만(2026-10-09):** `--done` 이 다운로드 폴더의 파일을 `work/<프로젝트>/gen_NN_*/받은/`로 복사하고(그림·영상은 워터마크를 지운 쓸 파일도 만듦) **다운로드 폴더의 원본은 지운다**. 결과 줄 '크롬 다운로드 폴더 원본: 지움'을 확인. 등록하지 않는 중복·잘못 받은 파일도 다운로드 폴더에 남기지 않는다.

## 1. 공통 — 크롬 확장 쓰는 법

| 규칙 | 이유·방법 |
|---|---|
| **새 탭(탭 그룹)에서만** | `tabs_context_mcp(createIfEmpty)` → 그 탭 id로만 `navigate`. 사용자가 열어 둔 탭은 덮어쓰지 않는다(게이트 EP03 사고) |
| **창이 가려지면(hidden) 스크린샷이 안 된다** | 오래 쓴 탭은 `visibilityState === "hidden"` 이 되며 스크린샷이 30초 뒤 시간 초과하고 **영상 제출·Flow Music 입력이 먹지 않았다**(그림 제출·AI Studio Run 은 됨). **해결: `tabs_create_mcp` 로 새 탭을 만들어 같은 주소를 열면 다시 그려진다**(스크린샷·클릭 정상). 그 전까지는 `javascript_tool` 로 DOM을 읽고 aria-label 로 버튼을 찾는다 |
| 값 넣기 | Flow 프롬프트 = ProseMirror(`div.ProseMirror`): `ed.focus(); document.execCommand('selectAll'); document.execCommand('insertText', false, 글)` → `ed.innerText === 글` 로 검증. 텍스트칸(textarea)은 네이티브 setter + `input` 이벤트 후 `.value` 로 검증 |
| **제출은 '진짜' 입력으로** | JS `button.click()` 은 생성 버튼에 안 먹는다(reCAPTCHA). **`computer key "Return"`(크롬 확장의 실제 키 입력)** 또는 `find` 로 찾은 ref 를 `left_click` |
| 긴 스크립트 금지 | 한 번의 `javascript_tool` 이 20초 넘게 돌면 확장 연결이 끊긴다. 그림 한 장씩, 짧게 |
| 누르지 않는 것 | 쿠키·약관 배너의 "동의함/나중에", 결제·구독·업그레이드(4K 업스케일), 계정·로그인 창. 로그인이 풀려 있으면 그 도구는 건너뛰고 보고 |
| Flow 메인에서 `Ctrl+A` 금지 | 프로젝트 전체 선택 → 휴지통 위험. 지울 땐 입력칸 안에서만 `selectAll` |

## 2. Flow — 그림 (Nano Banana 2.1, 0크레딧)

1. **새 프로젝트**: flow.google.com 홈 → `+ 새 프로젝트`. 제목칸(`수정 가능한 텍스트`)에 이름. 기존 프로젝트(게이트 등)는 건드리지 않는다.
2. 오른쪽 **에이전트 패널은 닫는다**(`닫기`) → 아래 가운데 프롬프트 막대가 나온다. `에이전트` 알약을 눌러 **에이전트 모드 끔**(설정 칩이 보이면 직접 생성 모드).
3. **설정**(`설정 트리거` 칩): `이미지` · 비율 `16:9`(세로 영상이면 `9:16`) · 모델 `Nano Banana 2.1` · `x1` → "생성 시 0 크레딧". 바깥을 누르거나 Escape 로 닫기.
   - **Nano Banana Pro 도 0크레딧**(10/28): 2.1 보다 피부·빛이 훨씬 고급 — 실사·인물은 이쪽. 이미지 2K 업스케일은 실패하니 1K 원본으로 받는다.
   - 프로젝트를 다시 열면 설정이 마지막에 쓴 값(동영상·Omni 720p 8초)으로 돌아가 있다 → 그림 제출 전 칩을 꼭 확인(10/29).
4. **레퍼런스 붙이기**(인물 샷): `프롬프트 상자에 소재 추가`(+) → 에셋 패널에서 **Flow 이름으로 버튼을 찾아** 클릭 → (필요하면) `프롬프트에 추가`.
   - 패널이 열린 채면 다음 이름을 바로 클릭해도 붙는다. 붙은 수 = 프롬프트 막대의 `img[alt="소재 이미지"]` 개수.
   - **순서가 곧 image 1·2** (프롬프트의 "Image 1 is AUGUSTE …" 순서대로).
   - Flow 이름 = 받은 파일 이름에서 날짜를 뗀 것(예: `Man character design sheet`). `gen-jobs` 표의 레퍼런스 칸에 나온다.
   - **사진 올리기(2026-10-18 확인 — 골든 두 마리)**: 사용자가 준 사진(반려동물·제품·본인 사진 등)은 이렇게 올린다.
     ① 사진을 미리 1600px 안팎으로 줄여 둔다(큰 원본은 느림). ② 에셋 패널의 `미디어 업로드` 를 누르기 **전에** `javascript_tool` 로
     `HTMLInputElement.prototype.click` 을 잠깐 가로채 file input 을 잡아 둔다(OS 파일 창이 안 뜨게). ③ 크롬 확장 `file_upload` 로 그 input 에 파일을 넣는다.
     ④ 올라간 사진을 레퍼런스로 붙여 캐릭터 시트를 만들고, 다음 샷부터는 시트를 레퍼런스로. 실존 인물 얼굴 사진은 본인 동의가 있을 때만.
   - 업로드가 막히면 → 사용자에게 "사진을 Flow 창에 끌어다 놓아 주세요"(화면 녹화 중이면 좋은 장면이 됨). 그것도 어려우면 **캐릭터 시트를 Flow에서 먼저 생성**해 라이브러리에 두고 그것을 레퍼런스로 쓴다.
   - **다른 프로젝트 사진 다시 쓰기**: 에셋 패널 왼쪽 위 프로젝트 고르기 칸에서 예전 프로젝트를 고르면 그대로 붙는다(다시 올릴 필요 없음).
   - **Flow '캐릭터' 기능**(10/26): 왼쪽 메뉴 캐릭터 → 신규 캐릭터 → 시트나 얼굴+전신 지정, 이름·설명 입력 → 에셋 패널(+)에서 이름으로 붙는다. 15샷이 같은 얼굴·옷으로 나왔고, 인물 편은 이걸 먼저 등록한다.
   - **무대(세트) 그림을 붙이면 구도까지 복사된다**(클로즈업이라 써도 30장 거의 전부 먼 와이드) → 세트 레퍼런스는 와이드 샷에만. 무대는 글로, 샷 크기(MEDIUM CLOSE-UP 등)는 프롬프트 맨 앞에. 옛 결과 그림도 붙이지 않는다(`_지식\색_효과_도구.md` 5절).
   - 패널을 검색어로 하나만 남기면 미리보기가 자동 선택돼 `프롬프트에 추가`만 누르면 된다. 생성 중엔 그리드가 밀리니 좌표 말고 `find` ref 로.
5. 프롬프트 넣기(위 '값 넣기') → **`Return` 키로 제출**. 제출되면 입력칸이 비고 레퍼런스도 빠진다. 여러 장을 연달아 넣어도 된다(동시에 생성됨, 한 장 20~40초).
6. **받기**: 그리드 타일(`img[alt="사용자 이미지를 표시하는 타일"]`, 새것이 앞) 클릭 → 편집 화면(`/edit/…`) → `미디어 다운로드` → 메뉴 `1K 원본 크기`(1376×768). 2K·4K(업그레이드)는 누르지 않는다.
   - 후보를 한 번에 받기: 타일 img 는 fetch 가 되므로 base64 로 묶어 JSON 한 파일로 받으면 60장도 한 번에(영상 주소는 fetch 막힘).
   - 받은 파일: `<크롬 다운로드 폴더>\<Flow 제목>_<날짜시각>.jpg`. **Flow 제목으로 샷을 짝짓고, 콘택트시트로 눈으로 확인한 뒤** `--done`.
   - 뒤로: `이전 페이지로 이동하는 뒤로 버튼`. 그리드 상태가 꼬이면 프로젝트 주소로 `navigate` 해서 다시.
7. 워터마크: 오른쪽 아래 ✦. `--done` 때 역산으로 지워진다(제거 전/후는 `gen_04_images/워터마크_확인.jpg`).

## 3. Flow — 영상 (기본 Omni 360p → 720p 업스케일, 크레딧!)

- **기본 = Omni 1.1 Flash · 360p (2026-10-19)**: "영상 생성은 플로우에서 할 경우 기본을 옴니 360으로, 업스케일해서 받는 걸로. 그렇게 하면 NG 컷을 감안하고도 훨씬 많이 만들어 볼 수 있어." — 360p 4초 ≈ 4크레딧(10/17 룩북 실측, Veo Lite 720p 8초 10크레딧의 절반 이하). 길이는 샷 길이에 맞게(4~8초, 설정 창 '생성 시 N 크레딧' 확인). NG(얼굴·생김 변함, 이상한 움직임)는 아끼지 말고 다시 뽑는다(재시도 한도 안). 사용자이 따로 말할 때만 Veo 3.1(Lite/Fast/Quality)·720p.
- **받을 때 업스케일(무료)**: 영상 타일 → 편집 화면 → `미디어 다운로드` → **`720p` 업스케일** 항목(360p 원본에는 1080p 선택지가 없음). 4K·'업그레이드'처럼 결제·구독으로 이어지는 항목은 누르지 않는다. 받은 파일 해상도를 ffprobe 로 확인(720p 세로 = 720×1280).
  - 720p 업스케일은 그 화면에 머물러야 20~60초 뒤 받아진다. 완료 전에 다른 화면으로 가면 사라지니(4개 걸고 1개만 받음) 한 개씩, 파일이 떨어진 걸 보고 다음 컷으로. 화면 위 미디어 띠로 다음 영상으로 넘어가면 빠르다.
- **360p 가 안 맞을 때**(10/28~30, 기본은 그대로 360p): 글자가 주인공인 배경, 화질이 특히 중요할 때는 **Omni 720p**(9:16 x1: 4초 7 · 6초 10 · 8초 12크레딧, 360p 는 4·5·6). `720p 원본 크기`가 메뉴에 바로 있어 기다림 없이 받아지고, 1080p 는 '업스케일링됨'(결제 아님, 몇 분). Veo 3.1 Fast 720p 8초 = 20크레딧, 받을 때 1080p 무료(`_1080p.mp4`) — 단 Veo 는 떠 있는 배너를 종이 카드로 바꾼다.
- **인물 컷은 마스터를 같이**(10/29 "컷 만들 때마다 마스터 캐릭터를 넣어줘야해"): 캐릭터는 영상 '소재' 모드에도 붙고 크레딧은 프레임 모드와 같다. 단 소재 모드엔 시작 칸이 없어 화면을 통째로 지어낼 수 있다(영어 가짜 인스타) → 화면이 중요하고 얼굴이 안 나오는 컷은 **프레임 모드**.
- **제출은 20초 간격으로 하나씩**(10/26): 몇 초 간격이면 "비정상적인 활동이 감지되었습니다" 실패, 20초 간격은 14개 연속 정상. 실패 타일은 '다시 시도'.
- 받은 뒤 프레임 4장(0.2/1.3/2.4/3.7초) 시트로 본다: 4초 안에서도 뒷부분에 카메라가 빠지며 엉뚱한 인물이 끼어들 수 있다 → 쓸 구간만 자른다.
- (아래는 10/8 Veo 시험 기록 — 모델·해상도만 위 기본으로 바꿔 읽는다. 'Veo' 글자 워터마크 자르기는 Omni 결과의 워터마크 위치를 눈으로 확인한 뒤 --done.)

- 설정: `동영상` · `프레임`(시작 프레임) · `16:9` · 모델 드롭다운 — **`Omni 1.1 Flash`(기본 — 360p로)** / `Veo 3.1 - Lite`(10크레딧, 10/8 시험 때 선택) / `Veo 3.1 - Fast`(20) / `Veo 3.1 - Quality` · **`360p`**(기본, Veo 를 쓸 땐 `720p`) · 샷 길이에 맞게 `4~8초` · `x1`. 설정 창 아래 "생성 시 N 크레딧"을 꼭 읽고 한도(`생성.영상_클립_한도`) 안에서만.
- 프롬프트 막대의 `시작` 칸 → 에셋 패널에서 그 샷 그림(Flow 이름) → `프롬프트에 추가` → 시작 칸에 그림이 들어감(`이미지 소재`).
- 움직임 프롬프트 넣고 제출.
- ⚠ 오래 쓴(hidden) 탭에선 영상 제출이 안 됐다 → **새 탭에서 프로젝트 주소를 열고** 하면 된다(2026-10-08: 새 탭에서 2클립 정상 생성, 각 약 1분).
- 받기: 영상 타일 → 편집 화면 → `미디어 다운로드` → (720p 원본이면) 메뉴 `720p 원본 크기` / (360p 기본이면) **`720p` 업스케일**(4K 업그레이드는 누르지 않음) → `<크롬 다운로드 폴더>\<제목>_<날짜>.mp4` (8초, 1280×720, 소리 포함).
- **동물 주인공**: 움직임 프롬프트에 "ears rising"처럼 생김을 바꾸는 말을 넣으면 다른 견종으로 변한다(2026-10-18 골든 → 귀 선 개). 생김은 못박고("floppy golden retriever ears stay down") 동작만 쓴다.
- 받은 뒤 그리드로 돌아갈 땐 `navigate back` 이 안전하다. 그리드 화면 왼쪽 위 (38,37)은 '홈' 버튼(편집 화면에선 '뒤로') — 좌표로 누르지 말 것. 영상 편집 화면은 다운로드 아이콘 자리가 그림과 다르다.
- 다운로드 아이콘: 그림 화면 (1110,33) / 영상 화면 (1020,34) — 영상에서 그림 자리는 '기록 숨기기'(10/30). `720p 원본 크기`는 메뉴 2번째.
- 워터마크가 둘: ① **시작 그림에 박혀 있던 ✦**(Flow 라이브러리 그림이 워터마크째 들어가므로 카메라를 따라 움직임) ② **오른쪽 맨 아래 'Veo' 글자**(고정).
  `--done` 때 오른쪽·아래 10% 띠를 잘라 내고 원래 크기로 되돌린다(역산은 자국, delogo 는 흐린 네모가 남아 비교 후 폐기). 그래서 **움직임은 'slow push in/dolly in'(가장자리가 밖으로 나가는 쪽)** 이 안전하다.
  시작 칸에 워터마크를 지운 그림을 올리면 ① 은 없어지지만 Omni 가 ✦ 를 새로 박는다(고정, 720 세로 x576~624·y1136~1184, 10/29). 카메라가 옆으로 트럭해도 10% 자르기면 괜찮았다.

## 4. AI Studio — 목소리

- 주소: `https://aistudio.google.com/generate-speech` (**`project=` 붙이지 말 것** — 403).
- 2026-10-08 화면: 첫 화면 카드 **`Create new dialog`** → 말 블록 편집 화면. 모델 칩 `Gemini 3.8 Flash TTS`(지침서의 3.1 대신 새 기본값).
- 목소리: 블록의 `Speaker 1 - <이름>` 또는 `Open voice settings` → "Speaker settings" 창 → 검색칸에 이름(예: `Charon` — Informative · Lower pitch) → 그 이름을 클릭 → `Current voice` 가 바뀐 것 확인 → 닫기.
  목소리 목록이 새 이름(Bodi·Lumi·Koda…)으로 늘었지만 Charon·Kore·Puck 같은 예전 이름도 검색된다.
- 화자 1명: 블록 하나(`textarea[aria-label="Speech block text"]`)에 대본 전체(장면 사이 줄바꿈). **`Speaker 1:` 머리말은 빼고** 넣는다. 화자 2명 이상은 `Add speech block` 으로 화자별 블록.
- Style(Director's note)은 내레이션이면 비워 둔다. 시트콤처럼 연기가 필요하면 블록마다 자유 연기 지시("경상도 시골 80세 할머니…")가 먹는다(10/26, 목소리 2,000개 넘음). Voice Design(새 목소리 설계)은 유료 키가 필요해 쓰지 않는다.
- **`Run`**: `find` 로 ref 를 찾아 `left_click` → 숨겨진 창에서도 됐다. `Stop` 버튼이 사라지면 끝.
  Run 이 aria-disabled 로 막힌 듯 보여도 ref 로 누르면 돈다. 글을 바꿔도 결과가 안 바뀌면 새 대화로 다시 연다.
- `Download` 버튼 → `<크롬 다운로드 폴더>\Generated Audio <날짜> - <시각>.wav` (24kHz 모노). 71초 내레이션 약 40초 걸림.
- 안 되면(로그인·Run 무반응 2번) → `--fail` 두 번 → 윈도우 Heami 임시 음성(보고서에 '임시 음성').
- **(10/20) Flow 에는 TTS 가 없다** — 생성 설정은 이미지·동영상뿐. Flow Music 에 '말소리만'을 시키면 노래가 되고 가사를 지어냄. Omni 영상의 'Voiceover only' 는 받아쓰기는 맞지만 **문장마다 따로 만들면 목소리가 바뀐다**(F0 238~304Hz). → 성우는 AI Studio 웹에서 **여러 문장을 한 블록에 한 번에** 생성하고(목소리 하나로 이어짐) 문장별로 자르기(받아쓰기 단어 시각 + 가장 조용한 자리). 고유명사(예: '슈주')는 받아쓰기가 틀리게 적을 수 있으니 귀로 확인. 숫자는 한글로(이천칠 년), 영문 약어는 소리대로(엠비씨).

## 5. Flow Music — 음악

- 주소: `https://www.flowmusic.app/` (Flow 홈의 `Flow Music` 링크). 로그인된 상태였음(PLUS).
- 첫 화면 `Compose` — 채팅 입력칸(`textarea[aria-label="Chat message"]`) + `Send message`.
- 길이는 믿지 말 것: 'about 16 seconds' 라고 해도 3분짜리 2곡이 왔다(10/27) → 곡 안에서 드롭과 드럼 빠진 구간을 재서 잘라 쓴다.
- 오래 쓴(hidden) 탭에선 입력이 안 들어갔다 → **새 탭**에서 열고, 입력칸을 실제로 클릭 → 글을 넣고 → `Return`. 보내면 세션이 생기고 "Producer"가 곡을 만든다(약 1분, 프롬프트에 길이 'about 80 seconds'를 넣으면 [End - 1:20]).
- 받기: 곡 줄의 더보기(⋯) → `Download` → 형식. ⚠ **마우스로 하위 메뉴를 누르면 메뉴가 닫혀 아무 일도 안 일어난다**(2026-10-08 처음에 실패한 원인).
  **키보드로**: ⋯ 클릭 → `ArrowDown` 으로 `Download` 까지 → `ArrowRight`(하위 메뉴 열림, 첫 줄 'Download video'에 초점) → `ArrowDown` 으로 `M4A` 까지(2026-10-08엔 4번 — 줌으로 초점 확인) → `Return`.
  → `<크롬 다운로드 폴더>\<곡 제목>.m4a`(제목의 ':' 는 '_'로 바뀜, 80초 곡 약 1MB, AAC 48kHz 스테레오). 스크린샷(zoom)으로 초점이 M4A 에 있는지 보고 누를 것.
  WAV 는 같은 다운로드 주소에 format=wav 로 직접 요청하면 403 이었다 — M4A 로 충분(배경음악).
- 등록: `--done music_main --file "<크롬 다운로드 폴더>\<곡 제목>.m4a"` (wav 로 바꿔 music/본편.wav). 곡 수 한도 `생성.음악_한도`(기본 3).
- **(10/20) 메뉴로 받아지지 않을 때**(확장 클릭으로 3번 실패한 적 있음): 재생한 곡은 `performance.getEntriesByType('resource')` 에 `storage.googleapis.com/producer-app-public/clips/<id>.m4a` 공개 주소로 보이고, 그 주소로 바로 받으면 된다. Flow Music 은 한 번에 2곡을 만든다. 받은 곡은 BPM 을 모르니 박자부터 재고, **드롭은 실제로 크게 터지는 시각(10ms 크기)으로 위상을 확인**(지속 베이스 곡에서 8분음표 하나 어긋나게 잡힌 적 있음 — `_지식\소리_목소리.md`).
- 대체: 키트 기본 배경음(`kits/audio/기본_배경음.wav`) 반복 또는 패드 합성 — 외부 곡을 받지 않는다.
