LUMIÈRE GEN System 사용법

주제나 대본만 주세요. 대본·콘티·그림·움직이는 장면·목소리·배경음악·자막·썸네일까지 제작팀(AI)이 만들어 완성 영상으로 냅니다. 촬영본 편집은 자매 제품 뤼미에르 에디트에서 해요.

01시작하기

  1. 뤼미에르 젠 폴더의 LUMIERE_GEN_시작을 더블클릭합니다.
  2. 브라우저에서 http://localhost:8431 이 열립니다. 이 화면이 대시보드예요. 내 PC 안에서만 열리고 밖에서는 접속할 수 없습니다.
  3. 처음이면 위쪽 Claude 연결됨 · 첫 만남 하기를 눌러 제작 팀장 오귀스트와 첫 만남을 해 주세요. 화풍·분위기·목소리·피할 것을 물어보고 그대로 기억해요.
준비물 크롬 + Claude in Chrome 확장, 그리고 그 크롬에서 Google Flow · Google AI Studio · Flow Music 로그인. 그림·영상·음악·목소리는 Claude가 이 크롬을 움직여 만들어요(따로 API 키가 필요 없어요).

02새로 만들기

  1. 아래쪽 ＋ 새로 만들기를 누릅니다.
  2. 주제를 쓰거나 대본 파일(txt·md·docx·hwp·hwpx)을 고릅니다. 대본을 주면 내용은 그대로 두고 장면만 나눠요.
  3. 길이(초)·화풍(예: 따뜻한 수채화풍 일러스트)·화자 수·가로/세로를 고르고 ▶ 만들기. 처음 값은 설정의 '생성' 묶음 기본값이에요.
  4. 제작팀이 대본과 콘티(샷 목록 — 인물·카메라·조명)를 만들고, 그림·영상·목소리·음악 작업 목록을 적은 뒤 "브라우저 작업 대기"에서 멈춰요.

03브라우저 작업 — "생성 작업 해 줘"

멈추면 화면 맨 위에 노란 띠가 뜨고 알림음이 울려요. 아래 브라우저 작업 표에 그림·영상·목소리·음악 작업이 보여요.

  1. 대화창이나 Claude 앱(Code) 창에 생성 작업 해 줘라고 말해 주세요.
  2. Claude가 크롬에 새 탭을 열어 Flow에서 캐릭터 시트 → 장면 그림 → 움직이는 장면(Veo), AI Studio에서 내레이션, Flow Music에서 배경음악을 만들어 받아 와요. 받을 때마다 표가 ✅로 바뀌어요.
  3. 다 받으면 자막(목소리에 정확히 맞춤)·컷 배치(그림은 천천히 확대·이동, 컷 사이 디졸브)·배경음악(말할 때 자동으로 작아짐)·종편(음량 맞춤)·썸네일·제목·설명까지 자동으로 이어 가요.
  • 크레딧 — 그림은 0크레딧. 움직이는 장면(Veo)과 음악은 설정 '생성' 묶음의 한도(기본 영상 4클립·음악 3곡) 안에서만 만들어요.
  • 워터마크 — Flow 그림·영상의 ✦ 표시는 받을 때 자동으로 지워요.
  • 얼굴 일관성 — 반복해서 나오는 인물은 캐릭터 시트를 먼저 만들고, 모든 장면 그림에 그 시트를 붙여 같은 사람으로 그려요.
  • 못 만들었을 때 — 움직이는 장면은 그림을 천천히 확대하는 장면으로, 목소리는 컴퓨터 기본 음성(임시)으로, 음악은 기본 배경음으로 대신하고 결과 요약에 적어 둬요.
멈춘 걸까, 일하는 중일까? 오른쪽 위에 초록 점과 "작업 중 · 마지막 소식 12초 전"이 보이면 일하는 중이에요. 노란 띠가 있으면 브라우저 작업을 기다리는 중이에요.

04진행 화면 보는 법

  • 왼쪽 — 13단계 진행표(의뢰서 → 대본 → 콘티 → 그림 → … → 마무리 보고).
  • 가운데 — 로봇 제작팀이 지금 하는 일 + 로그. ROBOT ⇄ PGM으로 실제 그림 화면과 바꿔 볼 수 있어요. 아래는 콘티 스토리보드(누르면 크게).
  • 오른쪽 — 남은 브라우저 작업 수, 그림·영상·목소리·음악을 몇 개 받았는지, 제작 로그.
  • 아래 — 결과물(누르면 파일이 열려요), 대화창, 완성본 미리보기.
  • 끝나거나 확인할 차례가 되면 컴퓨터 알림(윈도우 알림·맥 알림 센터)이 떠요(설정에서 끌 수 있어요).

05말로 고치기(대화창)

대화창에 평소 말투로 쓰면 제작팀이 알아서 명령으로 바꿔 실행해요. 🎤로 말해도 됩니다. 바뀐 단계부터만 다시 만들어요.

생성 작업 해 줘

썸네일 강조색 노랑으로

장면 대사를 고치면 목소리부터 다시 만들어요(목소리 작업이 다시 생겨서 "생성 작업 해 줘"가 한 번 더 필요해요). 그림 하나를 고치면 그 그림만 다시 그려요.

지금 기능으로 안 되는 요청은 설정 창의 만들 기능 목록에 남아요. 키우기 모드를 켜면 내 Claude가 그 목록을 보고 직접 만들어 줘요.

07만든 영상 다시 불러오기

  1. 대시보드 아래쪽 프로젝트 고르기 칸에서 예전 영상을 고릅니다.
  2. 대화창에 고칠 내용을 말하세요. 바뀐 단계부터만 다시 만들어요.
설정은 영상마다 기억해요 다른 영상을 만들며 팔레트·글꼴을 바꿨어도, 예전 영상은 처음 만들 때 설정 그대로 다시 만들어져요. 그 영상만 바꾸고 싶으면 대화창에 "이 영상 팔레트 B로"처럼 말하세요.

10내 스타일로 키우기 · 되돌리기 · 초기화

뤼미에르 젠은 완성품이 아니라 쓰면서 내 스타일로 키워 가는 제작 시스템이에요. 설정에서 '키우기 모드(개발자 모드)'를 켜면 대화창의 Claude가 제작팀 코드를 직접 고쳐 새 기능을 만들어 줘요.

  • 엔진(제작 프로그램)은 고쳐도 언제든 되돌릴 수 있어요. 개발자 모드로 대화할 때마다 고치기 전 상태가 자동 저장돼요.
  • 내 스타일(설정·프리셋·스타일 노트)과 영상 작업물은 초기화해도 그대로예요.
  • 설정 → 엔진 관리에서 이 상태로 되돌리기 또는 공장 초기화를 누르면 대시보드가 새 엔진으로 다시 켜져요.

자가 검사

엔진을 고친 뒤 자가 검사를 누르면 시험 대본과 시험 파일(실제 Flow·AI Studio 결과물)로 13단계를 브라우저 없이 끝까지 돌려요(가로+세로, 몇 분). 망가진 곳이 있으면 어느 단계에서 왜 멈췄는지 알려 줘요.

스타일 팩 — 내 스타일 나누기

내 스타일 내보내기는 내 설정·프리셋과 내 Claude가 고친 엔진 코드를 파일 하나(.zip)로 묶어요. API 키는 들어가지 않아요. 남이 만든 팩은 코드가 들어 있을 수 있으니, 믿을 수 있을 때만 '코드까지' 가져오세요.

11문제가 생겼을 때

증상이렇게
브라우저 작업이 안 됨크롬에서 Flow·AI Studio·Flow Music 로그인이 풀려 있지 않은지 확인하세요(로그인은 직접). Claude in Chrome 확장이 연결돼 있어야 해요.
얼굴이 장면마다 달라요대화창에 "S03 그림 얼굴이 시트랑 달라, 다시 그려 줘". 캐릭터 시트를 붙여 그 그림만 다시 그려요.
음악이 너무 커요/작아요"음악 좀 더 작게" — 설정 '배경음악 크기'를 바꾸고 조립부터 다시 만들어요.
오류로 멈춤도와줘 — 오류 고쳐 줘를 누르면 원인을 쉬운 말로 설명하고, 고칠 수 있으면 다시 돌려요.
대시보드가 안 열림LUMIERE_GEN_시작을 다시 실행. 만들던 작업은 끝난 단계까지 저장돼 있어서 이어서 됩니다.

12꼭 지켜 주세요

  • 업로드는 자동으로 하지 않아요. 유튜브에 올릴 때 'AI로 만든 콘텐츠' 항목을 체크해 주세요.
  • Flow·AI Studio 로그인·결제·약관 동의는 직접 하세요(Claude는 누르지 않아요).
  • API 키·비밀번호는 설정 창에 넣지 말고 폴더의 .env 파일에만 두세요.
  • 실존 인물을 다룰 때는 사진처럼 재현하지 말고 그림체로, 사실만 담아 주세요.
  • 대시보드는 내 PC에서만 열려요(다른 기기·인터넷에서 접속 불가).
